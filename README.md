# 🏋️ SunFit - Gym Website  

A fully responsive and animated Gym website built using **HTML, CSS, and JavaScript**. It provides users with an interactive experience to explore gym services, classes, schedules, and pricing.  

---

## 🚀 Features  
✅ Responsive Design (Works on all devices)  
✅ Animated Sections using **WOW.js**  
✅ Interactive Navigation Bar  
✅ Smooth Scrolling & Accordions  
✅ Pricing Plans & Membership Options  
✅ Contact Form for User Inquiries  
✅ Workout Gallery Section  

---

## 🛠️ Technologies Used  
- **HTML5** - Structure  
- **CSS3** - Styling & Animations  
- **JavaScript (jQuery & WOW.js)** - Interactivity  
- **FontAwesome** - Icons  

---

## 📌 How to Run the Project  
1. **Clone the repository**  
   ```sh
   git clone https://github.com/your-username/gym-website.git
   cd gym-website
   ```
2. **Open `index.html` in your browser**  
   ```sh
   open index.html  # (Mac)
   start index.html  # (Windows)
   ```
